Pneumonia Classification

Upload a chest X-ray and get a predicted class with a confidence score, powered by a Keras image classifier.

Open the app

How it works

1. UploadChoose a PNG, JPG or JPEG chest X-ray.
2. PreprocessThe image is resized to 224×224 and normalized.
3. ClassifyThe model returns a label and a confidence score.

Run it locally

  1. Install dependencies: pip install -r requirements.txt
  2. Place your model at models/pneumonia_classifier.h5
  3. Start the app: streamlit run app.py
  4. Open http://localhost:8501 in your browser
Important: This tool is for educational purposes only. It is not a medical device and its output is not a diagnosis. Always consult a qualified healthcare professional.
Built with Streamlit, TensorFlow and Keras.
